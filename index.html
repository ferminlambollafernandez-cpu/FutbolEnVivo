3. Conectar otro dispositivo

Primero activá tu cámara o pantalla. Después creá una sala y compartí el código con el otro dispositivo. En el otro dispositivo abrí esta misma página e ingresá el código para recibir la imagen recortada.

CÓDIGO DE ESTA SALA

Sin conexión con otros dispositivos.

La conexión usa WebRTC con PeerJS para establecer el enlace. El código de sala funciona como una clave de acceso: compartilo solo con quien quieras que vea la transmisión. La señalización inicial usa un servicio externo de PeerJS.

Compatibilidad del iPad

La cámara requiere permiso y una dirección HTTPS (GitHub Pages sirve). Compartir pantalla depende de que Safari/iPadOS exponga getDisplayMedia; si no está disponible, la página mostrará un aviso. No se puede forzar esa función desde el sitio.
